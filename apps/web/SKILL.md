# SKILL: Web App (`apps/web`)

## Purpose
`apps/web` is the main browser-facing CommandRelay app surface for local web fallback and extension presentation.

## Key Commands
- Open directly: `apps/web/index.html`
- List discoverable apps/extensions: `npm run discover:apps`
- List discoverable skills: `npm run discover:skills`

## Extension CLI Command
- Show app metadata: `npm run extension:run -- web info`
