# SKILL: Proxy Fetch (`packages/proxy-fetch`)

## Purpose
`@termina/proxy-fetch` provides proxy-aware fetch wrappers with timeout and JSON safety controls.

## Key Commands
- Type check: `npm run --workspace @termina/proxy-fetch check`
- Build: `npm run --workspace @termina/proxy-fetch build`
- Tests: `npm run --workspace @termina/proxy-fetch test`

## Extension CLI Command
- Metadata/help: `npm run extension:run -- proxy-fetch info`
- Run package checks: `npm run extension:run -- proxy-fetch check`
