# SKILL: Proxy Runtime (`packages/proxy-runtime`)

## Purpose
`@termina/proxy-runtime` provides a typed runtime controller for proxy decisions, settings reloads, and proxy-agent lifecycle management.

## Key Commands
- Type check: `npm run --workspace @termina/proxy-runtime check`
- Build: `npm run --workspace @termina/proxy-runtime build`
- Tests: `npm run --workspace @termina/proxy-runtime test`

## Extension CLI Command
- Metadata/help: `npm run extension:run -- proxy-runtime info`
- Run package checks: `npm run extension:run -- proxy-runtime check`
