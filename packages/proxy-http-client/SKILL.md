# SKILL: Proxy HTTP Client (`packages/proxy-http-client`)

## Purpose
`@commandrelay/proxy-http-client` offers a proxy-aware JSON HTTP client with timeout and response-size limits.

## Key Commands
- Type check: `npm run --workspace @commandrelay/proxy-http-client check`
- Build: `npm run --workspace @commandrelay/proxy-http-client build`
- Tests: `npm run --workspace @commandrelay/proxy-http-client test`

## Extension CLI Command
- Metadata/help: `npm run extension:run -- proxy-http-client info`
- Run package checks: `npm run extension:run -- proxy-http-client check`
