# Route explanation

## Explain two URLs in human mode

```bash
termina-cli-proxy explain https://example.com https://api.internal.local
```

## Explain with JSON output

```bash
termina-cli-proxy explain --json https://example.com https://api.internal.local
```

## Skip optional proxy-agent details

```bash
termina-cli-proxy explain --no-agent https://example.com
```
