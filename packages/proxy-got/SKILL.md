# SKILL: Proxy Got (`packages/proxy-got`)

## Purpose
`@termina/proxy-got` provides got-friendly proxy agent resolution and apply helpers without requiring a got runtime import.

## Key Commands
- Type check: `npm run --workspace @termina/proxy-got check`
- Build: `npm run --workspace @termina/proxy-got build`
- Tests: `npm run --workspace @termina/proxy-got test`

## Extension CLI Command
- Metadata/help: `npm run extension:run -- proxy-got info`
- Run package checks: `npm run extension:run -- proxy-got check`
