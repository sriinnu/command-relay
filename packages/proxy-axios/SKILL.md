# SKILL: Proxy Axios (`packages/proxy-axios`)

## Purpose
`@termina/proxy-axios` provides axios-friendly proxy resolver/apply helpers built on `@commandrelay/proxy-agent`.

## Key Commands
- Type check: `npm run --workspace @termina/proxy-axios check`
- Build: `npm run --workspace @termina/proxy-axios build`
- Tests: `npm run --workspace @termina/proxy-axios test`

## Extension CLI Command
- Metadata/help: `npm run extension:run -- proxy-axios info`
- Run package checks: `npm run extension:run -- proxy-axios check`
