# @commandrelay/tui

![@commandrelay/tui brand mark](./docs/assets/commandrelay-tui-brand.svg)

Cross-platform terminal UI client for CommandRelay

## Install

```bash
npm install @commandrelay/tui
```

## Runtime

- Node.js `>=18`
- ESM package ("type": "module")

- Shared protocol-level primitives for CommandRelay components

- Reusable utilities for CommandRelay runtimes and toolchains
