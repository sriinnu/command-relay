# SKILL: Proxy Undici (`packages/proxy-undici`)

## Purpose
`@termina/proxy-undici` provides a proxy-aware Undici dispatcher factory for HTTP/HTTPS requests.

## Key Commands
- Type check: `npm run --workspace @termina/proxy-undici check`
- Build: `npm run --workspace @termina/proxy-undici build`
- Tests: `npm run --workspace @termina/proxy-undici test`

## Extension CLI Command
- Metadata/help: `npm run extension:run -- proxy-undici info`
- Run package checks: `npm run extension:run -- proxy-undici check`
