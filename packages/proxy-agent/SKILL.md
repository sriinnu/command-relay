# SKILL: Proxy Agent (`packages/proxy-agent`)

## Purpose
`@commandrelay/proxy-agent` builds protocol-aware proxy agents for `http`, `https`, `socks`, and `pac` configurations.

## Key Commands
- Type check: `npm run --workspace @commandrelay/proxy-agent check`
- Build: `npm run --workspace @commandrelay/proxy-agent build`
- Tests: `npm run --workspace @commandrelay/proxy-agent test`

## Extension CLI Command
- Metadata/help: `npm run extension:run -- proxy-agent info`
- Run package checks: `npm run extension:run -- proxy-agent check`
