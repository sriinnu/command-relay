# SKILL: Proxy Core (`packages/proxy-core`)

## Purpose
`@commandrelay/proxy-core` exposes core proxy environment parsing and resolution utilities used by higher-level proxy packages.

## Key Commands
- Type check: `npm run --workspace @commandrelay/proxy-core check`
- Build: `npm run --workspace @commandrelay/proxy-core build`
- Tests: `npm run --workspace @commandrelay/proxy-core test`

## Extension CLI Command
- Metadata/help: `npm run extension:run -- proxy-core info`
- Run package checks: `npm run extension:run -- proxy-core check`
