# Naming Conventions

CommandRelay uses internal Vedic names and public English aliases.

## Purpose

1. Preserve internal conceptual language.
2. Keep external interfaces globally accessible.

## Canonical Mapping

| Internal | Public |
| --- | --- |
| `Setu` | Relay Bridge |
| `Dvara` | Gateway |
| `Akasha` | Event Bus |
| `Smriti` | Session Memory |
| `Raksha` | Security Layer |

## Rules

1. Public API fields, endpoint names, and UI labels use English aliases.
2. Internal package names may use Vedic identifiers.
3. Documentation may show both names together on first mention.
